# Installation

## Requirements

- Python `3.11` or newer
- Access to a Telegram bot token

## Install dependencies

```bash
python -m pip install -r requirements.txt
```

If you also need package and documentation builds:

```bash
python -m pip install -r requirements-dev.txt
```

## Run the project

```bash
python -m queue_bot
```

If the package is installed into the environment, the console script can also be used:

```bash
queue-bot
```
