# Queue Bot

`Queue Bot` - это Telegram-бот для управления учебной очередью, расписанием занятий и контролем сдачи заданий. Проект объединяет интерфейс Telegram-бота для студентов и администратора, небольшой веб-интерфейс для просмотра расписания и очередей, а также хранение данных в SQLite.

## Структура проекта

- `queue_bot/main.py` - обработчики команд Telegram-бота, FSM-сценарии и HTTP API для веб-интерфейса.
- `queue_bot/database.py` - асинхронный слой работы с базой данных SQLite.
- `queue_bot/index.html` - статический веб-интерфейс, который отдаётся через `aiohttp`.
- `docs/` - исходные файлы документации проекта для MkDocs.
- `requirements.txt` - список runtime-зависимостей приложения.
- `pyproject.toml` - настройки пакетной сборки через `setuptools`.

## Зависимости

Основные зависимости проекта перечислены в [requirements.txt](requirements.txt):

- `aiogram` - работа с Telegram Bot API.
- `aiosqlite` - асинхронная работа с SQLite.
- `aiohttp` - встроенный HTTP-сервер и API для веб-интерфейса.
- `python-dotenv` - загрузка переменных окружения из `.env`.

Зависимости для разработки, пакетной сборки и сборки документации перечислены в [requirements-dev.txt](requirements-dev.txt).

## Переменные окружения

Приложение использует следующие переменные окружения:

- `BOT_TOKEN` - токен Telegram-бота.
- `ADMIN_IDS` - список Telegram ID администраторов через запятую.
- `PORT` - порт встроенного HTTP-сервера, по умолчанию `3000`.
- `WEB_URL` - публичный адрес веб-интерфейса, который открывается из Telegram.

Для локального запуска можно создать файл `.env` на основе [.env.example](.env.example).

## Установка и запуск

1. Установите Python версии `3.11` или выше.
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

4. Настройте переменные окружения в `.env` или в системной среде.
5. Запустите приложение:

```bash
python -m queue_bot
```

После установки проекта как пакета можно использовать консольную команду:

```bash
queue-bot
```

## Сборка пакета

Проект использует `setuptools` как систему сборки Python-пакета. Для сборки исходного архива и wheel-пакета установите зависимости для разработки и выполните команду:

```bash
python -m pip install -r requirements-dev.txt
python -m build
```

Результаты сборки появятся в каталоге `dist/`.

## Сборка документации

Документация проекта собирается с помощью MkDocs и `mkdocstrings`.

Для сборки статического сайта документации выполните:

```bash
python -m pip install -r requirements-dev.txt
python -m mkdocs build --strict
```

Собранная документация будет находиться в каталоге `site/`.

## Основные команды

```bash
# запуск приложения
python -m queue_bot

# сборка пакета
python -m build

# сборка документации
python -m mkdocs build --strict
```
